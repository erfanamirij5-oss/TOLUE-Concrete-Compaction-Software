# TOLUE Concrete Compaction Software

Engineering desktop platform for 3D concrete packing, compaction, mix visualization, comparison, and standards-based analysis.

## Status

Initial architecture bootstrap in progress.

## Core product principles

- Project-based concrete mix workspace
- 1 m³ interactive 3D concrete specimen
- Aggregate, binder, water, admixture, SCM and void phase visualization
- Packing and compaction analysis
- Mix-to-mix comparison
- Section and transparency tools
- Engineering diagnostics and reporting
- Windows desktop distribution

> Product name rule: primary project roots and distributable artifacts use **TOLUE Concrete Compaction**, not TOLUE alone.
